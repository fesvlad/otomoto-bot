# otomoto-bot

Telegram-бот, который следит за поиском на [Otomoto.pl](https://www.otomoto.pl) и присылает:

- 🚗 **новые объявления** с фото, ценой, годом, пробегом, мощностью;
- 🔥 **оценку цены**: насколько дешевле или дороже похожих машин (та же модель, близкий год и пробег), плюс оценка самого Otomoto (проценты в сообщениях не показываются, только 🔥). Выгодные приходят со звуком, остальные без звука;
- 📉 **крупные снижения цены** (от 3 000 zł и 3%, считая все мелкие снижения вместе), только если после снижения машина не дороже похожих или Otomoto оценивает её «ниже рынка»;
- 🌍 **страну происхождения**, 🇵🇱 регистрацию в Польше, частник или дилер, «без аварий», первый владелец, сервисная история;
- ⚠️ **тревожные слова** из описания (uszkodzony, do naprawy, po wypadku, anglik, copart…).

## Как это работает

- `bot.py` открывает первую страницу поиска (сортировка «сначала новые») и сравнивает её с тем, что уже видел (`seen.json`).
- Раз в час он просматривает все страницы поиска: так собирается статистика цен для сравнения и ловятся снижения цен.
- Запускается через GitHub Actions (`.github/workflows/check.yml`): каждые 2 минуты его «будит» cron-job.org, и раз в 10 минут запасной запуск от самого GitHub.

## Настройки (Settings → Secrets and variables → Actions)

| Где | Имя | Что вписать |
|---|---|---|
| Secrets | `TELEGRAM_TOKEN` | токен бота от @BotFather |
| Secrets | `CHAT_ID` | номер группы, например `-5472445158` |
| Variables | `SEARCH_URL` | ссылка поиска с Otomoto (можно несколько, каждую с новой строки) |

## Как поменять фильтры

Settings → Secrets and variables → Actions → вкладка **Variables** → `SEARCH_URL` → вставьте новую ссылку.

## Ручной запуск

Actions → «Проверка Otomoto» → **Run workflow**.
