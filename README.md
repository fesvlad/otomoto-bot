# otomoto-bot

Telegram-бот, который каждые ~10 минут проверяет поиск на [Otomoto.pl](https://www.otomoto.pl) и присылает новые объявления в Telegram.

## Как это работает

1. GitHub Actions запускает `bot.py` каждые 10 минут (файл `.github/workflows/check.yml`).
2. Бот открывает вашу ссылку поиска (с сортировкой «сначала новые») и собирает объявления.
3. Сравнивает их со списком уже виденных (`seen.json`).
4. О новых присылает сообщение в Telegram: фото, цена, год, пробег, город, ссылка.
5. При первом запуске просто запоминает всё, что есть сейчас, без рассылки.

## Настройки (Settings → Secrets and variables → Actions)

| Где | Имя | Что вписать |
|---|---|---|
| Secrets | `TELEGRAM_TOKEN` | токен бота от @BotFather |
| Secrets | `CHAT_ID` | номер группы, например `-5472445158` |
| Variables | `SEARCH_URL` | ссылка поиска с Otomoto (можно несколько, каждую с новой строки) |

## Как поменять фильтры

Откройте Settings → Secrets and variables → Actions → вкладка **Variables** → `SEARCH_URL` → вставьте новую ссылку.
Для новой ссылки бот сначала пришлёт «Бот запущен», а потом только новые объявления.

## Ручной запуск

Actions → «Проверка Otomoto» → **Run workflow**.
